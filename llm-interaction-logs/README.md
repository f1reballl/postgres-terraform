# LLM Interaction Logs

Place the original, complete Codex session JSONL file in this directory when
agents are used for the assignment.

For every saved log, record:

- the tool used;
- the session date; and
- the export or copy method.

Logs must not be fabricated or selectively edited. Before public publication,
review every log for accidental secrets. Document any necessary redactions,
including what was redacted and why.
