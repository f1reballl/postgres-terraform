# Agent Workflow

This repository is a local-only DevOps take-home assignment. Do not deploy,
publish, or otherwise change external infrastructure unless a later assignment
explicitly authorizes it.

- Use reproducible commands for all work and document any required manual steps.
- Make one or more focused commits for each assignment task.
- Never commit Terraform state, generated credentials, provider caches, secrets,
  or other sensitive material.
- Verify the relevant result before declaring an assignment task complete.
- When agents are used, preserve the full LLM interaction logs in
  `llm-interaction-logs/`.
